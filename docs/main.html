ABOUT THE PROJECT

What is SlideSense?

Understanding the conditions before a landslide occurs is the first step toward building safer communities.

Landslides can happen suddenly. The warning signs often develop gradually.

SlideSense is an AI-enhanced IoT landslide monitoring system designed to continuously observe environmental and geological conditions in landslide-prone areas.

A network of field sensors collects rainfall, soil moisture, slope movement and vibration data. These measurements are transmitted to the cloud for continuous monitoring and intelligent risk analysis.

By identifying potentially dangerous changes early, SlideSense aims to provide timely warnings that support faster decisions and safer communities.

FINAL HARDWARE ASSEMBLY

From Individual Modules to a Complete Field System

The final SlideSense prototype integrates the subsurface sensor probe, rainfall monitoring, embedded control, positioning, cellular communication and solar power into one deployable landslide monitoring platform.

FINAL PROTOTYPE
UNIT 01 · SUBSURFACE SENSOR SYSTEM

Final Multi-Sensor Probe

The SlideSense probe is designed to be inserted vertically into the monitored slope and collect measurements from multiple positions below the ground surface.

✓
Multi-Depth Soil Moisture Measurement

Three soil-moisture sensors provide readings from different probe positions, allowing the system to estimate overall soil saturation more reliably.

✓
Slope Condition Monitoring

The probe structure allows additional ground-movement and vibration sensing to be integrated with the moisture data.

✓
Field-Replaceable Connection

The probe connects to the main control unit through a dedicated wired interface for practical installation and maintenance.

RAINFALL MONITORING
UNIT 02 · RAINFALL MONITORING

Tipping Bucket Rain Gauge

Rainfall is one of the most important environmental factors influencing slope instability. SlideSense uses a tipping bucket mechanism to continuously measure accumulated rainfall.

✓
Hall-Effect Tip Detection

Each bucket movement is detected electronically and counted by the ESP32.

✓
Rainfall Conversion

Each recorded tip corresponds to approximately 0.173 mm of rainfall, allowing real-time rainfall accumulation to be calculated.

✓
Continuous Outdoor Monitoring

The rain gauge operates alongside the subsurface probe and transmits its readings through the same SlideSense field node.

CONTROL UNIT INTERNALS
UNIT 03 · EDGE CONTROL & COMMUNICATION

Main Control Unit

The central field unit integrates processing, communication, positioning and power management hardware into a single embedded control assembly.

✓
ESP32 Controller

Reads sensor measurements, performs local preprocessing and prepares telemetry for cloud transmission.

✓
SIM / GSM Communication

Provides cellular connectivity for transmitting sensor data from remote landslide-prone areas.

✓
GPS Positioning

Associates monitoring data with the geographic location of the deployed node.

✓
Buck Converter & MPPT Power Control

The power stage regulates the solar supply and provides stable operating voltages for the embedded electronics.

COMPLETE FIELD STATION
UNIT 04 · POWER & FIELD DEPLOYMENT

Solar-Powered Monitoring Stand

The final above-ground SlideSense station brings together the solar power system, main control unit, communication hardware and rainfall monitoring equipment on a single field-deployable structure.

✓
Solar-Powered Operation

The mounted solar panel supplies renewable energy to the monitoring station, supporting operation in remote landslide-prone areas where grid power may not be available.

✓
Integrated Main Control Unit

The control enclosure houses the ESP32, communication modules and power-management electronics required to collect and transmit environmental sensor data.

✓
Integrated Rainfall Monitoring

The tipping bucket rain gauge is positioned as part of the field station to continuously measure rainfall while the underground probe monitors soil conditions.

✓
Field-Deployable Structure

The supporting stand provides a practical mounting platform for the solar panel, electronics and monitoring equipment during outdoor deployment.
